# Introduction

> **Nguồn:** [Introduction](https://go.dev/doc/effective_go#introduction) · [Effective Go](https://go.dev/doc/effective_go)

Go hướng tới **đơn giản, tin cậy, hiệu quả** — phù hợp hệ thống lớn. Dịch thẳng từ C++/Java thường **không** cho code Go tốt; cần học **idiom** và convention của Go.

Đọc trước khi vào repo này:

1. [Tour of Go](https://go.dev/tour/)
2. [How to Write Go Code](https://go.dev/doc/code)
3. [Language Spec](https://go.dev/ref/spec)
